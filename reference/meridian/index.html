Four principles

The rules that hold on every engagement.

A

Start from the decision

We name the business decision the system must improve before we ever name a model. If we can’t, we’re not ready to build.

B

Evaluate before you scale

Nothing ships without an offline eval set and a threshold agreed in advance. We measure the thing, then decide.

C

Keep a human on the gate

Every automated decision has a named owner and a reviewable trail. Accountability doesn’t disappear because a model made the call.

D

Hand back the keys

The engagement ends when your team can run and change it without me. Good advice makes itself unnecessary.

The engagement

Four phases. You always know which one you’re in.

# Phase What has to be true to move on What comes out of it
01 Frame We agree the decision and the metric. A decision map and a shortlist of use cases, ranked by value over effort.
02 Prove The prototype clears the agreed threshold. A working prototype, an eval harness, and a go / no-go you can defend.
03 Ship Owners, monitoring and rollback are in place. A production system your team operates, not a demo.
04 Handover Your team can run and change it alone. Runbooks, a trained team, a scheduled check-in — then I’m gone.
